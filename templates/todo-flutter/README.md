# Todo (Flutter)

> This is a **placeholder** template. It provides the agent workflow, a worked example PRD, and Flutter-specific agent skills — but no Flutter project code yet.

## Getting Started

1. Create a Flutter project in this directory:
   ```bash
   flutter create . --project-name todo
   ```
2. Install dependencies listed in the AGENTS.md tech stack:
   ```bash
   flutter pub add flutter_riverpod go_router hive_flutter
   flutter pub add --dev build_runner hive_generator
   ```
3. Open `docs/tasks/todo-0001-add-todo-input.md` — your first task!

## Why a Placeholder?

The point of this starter is to **learn by building**. The docs, PRDs, tasks, and agent skills are all set up — you just need to write the Dart code. Hand the task file to your AI agent and pair-program your way through it.
